## ⬜ O que falta (manual — só você faz)

### A. Domínio e site
1. [ ] **Comprar o domínio** — `.com.br` (registro.br, ~R$ 40/ano) ou `.com` (Hostinger/GoDaddy)
2. [ ] **Trocar `SEU-DOMINIO.com.br`** pelo domínio real nestes 5 arquivos:
   - `index.html` · `ler.html` · `sitemap.xml` · `robots.txt` · `llms.txt`
3. [ ] **Criar a imagem da capa** `capa.jpg` (1200×630px) — para compartilhamento nas redes
4. [ ] **Ativar o GitHub Pages** → GitHub: *Settings → Pages → Deploy from a branch → main → / (root)*
5. [ ] **Apontar o domínio** para o GitHub Pages (CNAME/DNS no registro.br)
6. [ ] **Enviar o sitemap** no Google Search Console

### B. Validação (beta readers)
7. [ ] **Recrutar 5–10 beta readers** (mulheres de 28–45, casadas/separadas/divorciadas)
8. [ ] **Enviar** `manuscrito_beta.html` + questionário (`BETA_READERS.md`)
9. [ ] **Coletar e aplicar** o feedback

### C. Publicação (Amazon)
10. [ ] **Revisão final em voz alta** (opcional, recomendada)
11. [ ] **Criar a capa final do livro** (ver `BRIEFING_CAPA.md`)
12. [ ] **Publicar na Amazon** (seguir `PASSO_A_PASSO_AMAZON_KDP.md`)
13. [ ] **Adicionar o link da Amazon** no site (trocar o botão "em breve")

### D. Marketing
14. [ ] **Criar perfis** nas redes (Instagram, TikTok)
15. [ ] **Linkar as redes** no rodapé do site (trocar os `href="#"`)
16. [ ] **Pedir avaliações/resenhas** (Amazon, Goodreads, Skoob)
17. [ ] **Divulgar** (lançamento, posts, grupos de leitura)
